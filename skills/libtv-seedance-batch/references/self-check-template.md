# Pilot 验证与 480P 出片自检规范

## 一、1~2 镜 Pilot 验货检查项（放开批处理前必查）

> **交接节点**：第 1–2 项在用户点击「生成」前先在画布自检就绪；第 3–4 项及下表在用户在画布手点生成出 480P 样片后拉片核验。

1. **画布排版与遮罩是否规范**：分组明确（网页新建的 `深度动作捕捉-*` 节点已通过 `libtv group` 纳入本镜分组）、节点未叠压、原片与景深节点区分清晰（严格从左往右排布）；若做过构图图局部涂白，确认仅遮住错位五官/帽饰等最小必要区域，完整保留衣领/肩背/服饰光影且无残影漏边。
2. **深度动作捕捉连线、素材顺序与参数正确**：已通过 `chrome-devtools` 刷新画布并打开 `S01-样片` 生成面板截图验真——入边只有「构图图 + 角色图 + 景深节点」，不含原片节点；**顶部缩略图 `1..N`（图片在前、景深视频在后）与正文首句 `{{Node ...}}`（`@图片1..@视频N`）顺序严格逐一对应**（不将 `视频N` 提前）；提示词不提涂白；参数为 `21:9` / `480P` / 整数秒 / 音频开启且未触发 `--run`。
3. **Seedance 合规一次通过**：无图片尺寸/比例拦截，无真人资产未入库拦截。
4. **出片风格、画幅与音画基本对路**：确认为 `21:9`、无字幕/水印、时长与对白节拍匹配原片。

## 二、480P 样片出片自检清单

每个样片生成后，Agent 下载样片回本地并对照**原片**与**参考图**逐项核查：

| 维度 | 核查内容 | 常见异常处理建议 |
| --- | --- | --- |
| **人物与角色一致性** | 五官、发型、服饰、体型、年龄感是否匹配角色参考图；有无出现多余人物/双胞胎 | 补充多视图/近景锚点说明，结尾加“画面中仅出现X名角色，不重复出现人物” |
| **构图与影调** | 空间布局、景别、光影色调、机位关系是否贴合构图参考图 | 提示词开头明确“构图与影调按 `{{Node ...}}`”，去掉与构图图冲突的景别词 |
| **动作与运镜还原** | 起幅/转折/停顿/落幅顺序、幅度、人物视线以及手持晃动/推拉摇移是否一致 | 补细微动作衔接、延长或调准节拍描述、核查深度视频时长是否与原片一致 |
| **对白与音频** | 台词原文是否完整清晰、说话人与口型/反应时机是否同步、有无错别字/吞音、有无意外配乐 | 检查 `{台词原文}` 是否断句合适、加上说话语气与“音频：没有音乐，保留同期对白与SFX” |
| **画质与禁忌** | 是否稳定 `21:9`、有无字幕、平台水印/Logo、极端手部/道具穿帮 | 强化“不要变形宽银幕炫光（按需）、保持无字幕，不生成水印或Logo” |

## 三、向用户的标准汇报模板

每次 Pilot 或一批 480P 样片自检完成后，按以下结构简洁汇报：

```markdown
### 样片出片自检汇报（<批次/镜头范围>）
- **画布直达**：https://www.liblib.tv/canvas?projectId=<画布UUID>

| 镜头 | 原片时长 → 设定秒数 | 自检结论 | 关键观察与建议 |
| --- | --- | --- | --- |
| S01 | 5.04s → 5s | ✅ 建议可转正片 | 动作/运镜贴合原片，对白清晰同步，主角形象一致 |
| S02 | 6.80s → 7s | ⚠️ 建议微调后重跑 | 结尾转身稍快、手部酒瓶略变形；建议补强手部动作细节 |

- **待确认台词（若有）**：<列出具体镜头与时间点，或写“无”>
- **下一步请确认**：
  1. 对 ✅ 的镜头是否直接执行 `libtv video final` 生成 1080P 正片？
  2. 对 ⚠️ 的镜头按上述建议修改重跑，还是你有额外调整意见？
```
