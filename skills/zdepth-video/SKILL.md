# 视频洗景深视频（720P Z-Depth 黑白灰阶深度图视频）

当用户要求“把视频洗成景深视频”或“改成景深视频”时，**无需追问歧义**，直接调用本技能目录下的脚本将输入视频转换为 **720P 近亮远暗黑白灰阶深度图视频（Z-Depth）**，供 Seedance / VACE / ComfyUI / 可灵等工作流洗视频、控运镜与空间表演使用。

## 一、默认核心规范（最高优先级）

1. **视觉形态：黑白灰阶 Z-Depth（近白远黑）**
   - 使用 `depth-anything/Depth-Anything-V2-Base-hf`（自动检测 NVIDIA `cuda` / Apple Silicon `mps` / `cpu` 加速；国内网络自动回退 `hf-mirror.com`）逐帧提取高精度视差图：前景近处亮白、中景中性灰、远景深黑，边缘锐利且彻底脱敏真实人脸纹理。
2. **输出分辨率强制 720P（零拉伸变形）**
   - 默认自动按原视频画幅输出标准 **720P** 分辨率（Lanczos 超采样 + 自适应边缘微锐化）：
     - **21:9 宽银幕**（宽高比 ≥ 2.05，如 `992×432`、`1680×720`）→ 固定输出 **`1680×720`**
     - **16:9 横屏**（宽高比 1.55–2.05）→ 固定输出 **`1280×720`**
     - **9:16 竖屏**（宽高比 ≤ 0.65）→ 固定输出 **`720×1280`**
     - 其他比例自动将短边对齐 `720`、长边对齐 `16` 的倍数。
3. **零落盘流式管道 + 防闪烁 + 音画 100% 同步**
   - 解码阶段直接通过 FFmpeg `Lanczos` 前置缩放到目标 720P 分辨率并通过内存管道送入逐批推理（零临时图片落盘，彻底免除 4K PNG 读写与大内存换页），推理结果以 `float16` 分块缓冲，大幅降低内存占用与长视频 OOM 风险。
   - 对全片逐帧 `1.0%` 与 `99.6%` 分位数做时间轴高斯平滑（σ = 18 帧）并配合运动自适应静态降噪，消除单帧极值跳变引起的背景呼吸闪烁，同时保证运动前景零拖影。
   - 自动适配 FFmpeg 4.x–9.x，通过单通道 `gray` 管道流式编码为 `H.264 High (CRF 15, preset medium, yuv420p)`，并默认 `-c:a copy` 无损保留原视频对白与音效音轨。

## 二、标准执行流程

设 `<SKILL_DIR>` 为当前 `SKILL.md` 所在的目录路径。

### 1. 确定输出文件路径
- 默认保存到用户当前工作区目录下：`<原视频名>_景深视频_720p.mp4`。

### 2. 一键执行转换
- **macOS / Linux（推荐）**：直接运行内置启动器 [run_zdepth.sh](./scripts/run_zdepth.sh)（已缓存依赖时离线秒启动，首次运行时通过 `uv` 自动拉取依赖与模型权重）：
  ```bash
  bash "<SKILL_DIR>/scripts/run_zdepth.sh" "<输入视频路径>" "<输出视频_景深视频_720p.mp4>"
  ```
- **Windows（或直接使用 `uv`）**：[video_to_depth.py](./scripts/video_to_depth.py) 已内置 PEP 723 依赖声明，可直接运行：
  ```powershell
  uv run "<SKILL_DIR>/scripts/video_to_depth.py" "<输入视频路径>" "<输出视频_景深视频_720p.mp4>"
  ```
  > 若目标机器尚未安装 `uv` 且当前 Python 环境未安装依赖，可先引导或自动安装 `uv`（macOS/Linux: `curl -LsSf https://astral.sh/uv/install.sh | sh`；Windows: `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"`），无需手动安装系统 FFmpeg（脚本内置 `imageio-ffmpeg` 二进制）。

#### 可选参数（仅在用户明确提出时启用）
- `--resolution 1654x720`：显式指定自定义分辨率
- `--exact-aspect`：不做标准 21:9 / 16:9 微裁切，严格按原片精确宽高比缩放到短边 720
- `--gamma 0.75`：提亮中后景暗部人物剪影层次（默认 `1.0` 标准线性视差）
- `--invert`：反转为近黑远白
- `--mute`：去除原视频音轨输出静音视频
- `--batch-size 4`：显式指定推理批大小（默认 `CUDA=8`、`MPS/CPU=4`；Apple Silicon 16 GB 统一内存建议保持 `4`–`8`，避免过大触发换页降速）
- `--preset fast`：调整 H.264 编码预设（默认 `medium` 兼顾速度与体积，可选 `fast` / `slow`）

### 3. 强制核验与交付（必做）
1. 运行完成后，查看生成的 `.mp4` 视频画面与流信息，确认：
   - 画面为近亮远暗黑白灰阶、边缘干净、无拉伸变形、无闪烁；
   - 分辨率为 `720P`（如 `1680×720` 或 `1280×720`），时长与原视频一致，原声音轨正常保留。
2. 向用户交付输出视频路径，并简明列出分辨率、帧数、时长与音轨状态。
