# 撰写技法（Seedance 2.5）

本文件补充写作结构、素材映射、动作备选、镜头术语、素材配置与文字生成技法；任务范围、节拍选择、音频、影调与输出偏好统一见 `../SKILL.md`。

## 1. 基础写作结构（含文生视频与参考生视频要素）

全新生成（纯文字或带参考素材）统一按以下四段式组织，将**精准主体、动作细节**（必需）与**场景环境、光影色调、镜头运镜、视觉风格、画质、约束条件**（建议）自然落入对应段落，不把动作、场景、运镜拆成互相脱离的平面列表：

| 段落 | 包含要素与写法 |
|---|---|
| **1. 素材指代**（有素材时） | 按上传顺序说明每个素材的用途；关键帧任务第一句先声明关键帧顺序，编辑/延长直接用触发词指明待处理视频 |
| **2. 一句话概述（场景与主体锚定）** | 简洁交代**时段、地点、精准主体、核心事件与天气**；一镜到底任务在此定性，并注明起幅景别与机位 |
| **3. 具体情节（动作细节＋镜头运镜）** | 按主文件的默认时间连词或用户确认的整数秒时间戳组织节拍，把**主体动作细节**与**摄影机运镜变化**融合在对应节拍里；用户要求的台词 `{}` 或音效 `<>` 放在对应时机 |
| **4. 收尾（光影＋风格画质＋约束＋音频）** | 补齐无影调参考时的`影像风格：`光影色调描述、固定摄影机与画质预设、本镜头相关排除约束及`音频：`总则 |

- **元指令不入正文**：“把重要素材放在前面”“用静态特征防漂移”等属于给写手的撰写策略，只用来指导排素材和组织信息，不写进交付给模型的提示词正文。
- **一镜到底 vs 多镜头**：二者需分别设计。仅把“镜头 N”改成时间戳，不能将跳切场景变成连续长镜头。用户明确要求多镜头时可用“镜头 N”；连续长镜头必须写出可实现的空间与运镜过渡。适配示例见 `examples.md`。

## 2. 素材指代与主体映射

绑定与外形精简规则见主文件「素材绑定与主体指代」。以下补充多素材组合方式（不只依赖图片内部文字标签）：

- **多主体消歧**：`{{Mixed 2}}：角色甲形象，对应 {{Mixed 1}} 中前景左侧人物。{{Mixed 3}}：角色乙形象，对应 {{Mixed 1}} 中后景右侧人物。`
- **同一角色多张素材**：同一角色有多张不同视角或拆分素材（如面部图＋服装图）时，将各张素材绑定到同一明确角色名；资产库 ID 不能替代正文里的 `{{Mixed N}}` 编号。
- **形象与音色**：用户要求音色参考时，分别说明某角色形象对应哪张图、音色对应哪段音频。
- **部分运动参考**：`{{Mixed 1}}：只参考施法动作。{{Mixed 2}}：只参考环绕运镜。` 需确认二者时序和空间是否兼容。
- **完整动作参考**：精准参考已有完整动作视频时，绑定动作与顺序即可；只补新要求，不再逐帧重复视频中的动作。

## 3. 时间连词与时间戳写法

格式选择与估时规则见主文件「工作流程与必要提问」「单镜头时序与运镜」「约束与输出」。

- **默认时间连词示例**：`角色先按下快门，随后保持姿势 1 秒，最后放下相机。` 局部动作的持续秒数不等于切换成时间戳格式，两种格式均可明确停留时长。
- **整数秒时间戳示例**（用户已确认使用时）：时间段可写 `0–3s……3–7s……7–15s……`；时间点可写 `第 5 秒开始向画面左侧横移。`
- 每段内容太少容易让模型自由发挥，太多可能遗漏或切碎；调整节拍分配时保留用户已确定的总时长与必要动作。

## 4. 动作与表情备选

表演数量、持续状态和必要动作的区别统一见主文件「表演细节与克制程度」。下表是候选动作池，每次只挑与角色、剧情和画内可见部位相符的少量细节，不能整行复制：

| 情绪 | 可选细节 |
|---|---|
| 悲伤 | 低头；眼眶泛红；泪水在眼眶里打转但没落下 |
| 喜悦 | 嘴角上扬；眉眼舒展；脚步轻快 |
| 紧张 | 呼吸变浅；短暂避开视线；手指轻扣桌面 |
| 愤怒 | 下颌绷紧；呼吸略重；语速略快、局部重音 |
| 释然 | 舒一口气；肩膀放松；露出淡淡微笑 |

用幅度、速度和时机控制程度（如“缓慢抬手”与“快速抬手”不是同一种表演）。明确的物理衔接步骤应保留（如“接稳杯子后，递杯者松手”），收敛情绪不等于省略关键操作。

## 5. 镜头语言与专项收尾补充

- **基础通识术语可直接写**：景别（大全景/全景/中景/近景/特写）、运镜（推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动）、机位（低角度/俯视/第一人称）。
- **热门运镜方式可直接写**：一镜到底、希区柯克变焦、航拍视角、FPV、子弹时间、手持镜头、回弹变速等。
- **小众或专业术语需转换为 `[名词 + 描述性解释]`**：
  - 示例：「移焦，画面焦点发生平滑转变，原本在前景清晰的树木变模糊，背景中的人物由模糊逐渐变得清晰。」
- **转场镜头写清触发点与方式**（只在用户允许场景转场时使用）：
  - 示例：「随后向画面左侧横移，前景墙面遮满画面后转入下一场。」
- **复合运镜**：优先简洁；用户需要复合运动时，写清各运动的关系和起止时机，不同时堆互斥方向。Dolly、变焦和固定机位的区别见主文件。
- **专项收尾排除补充**：除主文件固定预设与默认约束外，收尾只针对当前任务的特殊风险补简短说明——如多宫格/白模转写实可补“最终只呈现写实人物与场景，去除线稿、辅助网格与轨迹线”；复杂动作变形风险可补“人物面部与身体比例稳定，动作连续”。

## 6. 素材配置策略

把参考素材分成四种功能角色：

1. **角色锚定**：锁定角色外观（建议 1–2 张角色图）
2. **场景定调**：锁定环境、构图与影调风格（建议 1 张场景图）
3. **运镜/动作参考**：锁定镜头语言与动作节奏（按需加 1 段参考视频）
4. **节奏氛围**：用音频控制情绪、音色（仅在用户要求声音参考时添加，不为凑配置数量补不存在的素材）

**不要因为模型容量大就堆满素材上限**——过多素材会让模型难判断特征优先级，易出现风格冲突、主体识别模糊。在可安排上传顺序时，越需要精准参考的素材越靠前放置（此为排素材策略，不写进提示词正文）。

## 7. 文字生成

支持广告语、字幕、气泡等场景。优先用常用字，避免生僻字与特殊符号。模型能按情境自动匹配文字风格与颜色，也可指定。

通用句式：`「文字内容【…】」+「出现时机」+「出现位置」+「出现方式」+「文字特征（颜色、风格）」`

- **用户要求字幕时**：`画面底部出现【出发】，与角色说出对应内容的时机同步。` 同时移除默认无字幕约束。
- **用户要求气泡台词时**：`角色甲说{出发}，角色甲身旁同步出现气泡，气泡文字为【出发】。` 语音 `{}` 与可见文字 `【】` 分别绑定。
- **对文字/标识表现要求严格时**：可用图片提供 Logo 或标准字作参考（见 `examples.md` 的「广告语与 Logo」）。
