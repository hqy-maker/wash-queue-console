# 常见问题与对策（Seedance 2.5）

按实际症状选择处理办法，不把全部排错建议追加进每条提示词。任务范围、默认声音、影调、运镜和表演规则统一见 `../SKILL.md`；以下方法不保证每次生成成功。

## 人物 ID 漂移（换脸 / 撞脸明星 / 图文打架）

现象：生成角色与参考图不一致、视频中途换脸，或因撞脸明星被审核拦截。
根因：人脸参考图有效性不足（人脸与全身/服装细节混在一张图、人脸占比过小），或提示词里重复堆叠了与参考图冲突的外形描述。
对策：

- **拆分纯净大头照**：额外准备只含头部的人脸特写图（仅面部、无表情最佳，减少肩颈与背景干扰），将面部与妆造/服装分开绑定：`{{Mixed 1}}：角色甲面部特征参考。{{Mixed 2}}：角色甲妆造参考。`
- **删除冗余外形词**：按主文件「素材绑定与主体指代」，参考图能锁定的外形交给参考图（单人镜头不另写身份外形段，多人只写角色名＋构图位置），文字只保留本场的神态、情绪与动作朝向。
- **重要素材前置**：在可调整顺序时，把核心人脸/构图参考放在最前。
- **核对多视图**：检查同一人的多视图是否被误认成多人；按 `task-types.md`「素材输入建议」调整，并明确多张图属于同一角色。

## 双胞胎问题与参考人物过多

现象：同一画面出现两个完全相同的人物，或多人场景输出人数不符、角色重复。
对策：

1. **明确绑定与固定指代**：开头绑定 `{{Mixed 1}}` 为张三形象、`{{Mixed 2}}` 为李四形象，正文持续用固定角色名，不用括号重复素材绑定。
2. **补充防复制约束**：加“每个角色只出现一个对应人物”。若用户本就要求真实双胞胎或相同制服人物，则保留并用画面位置和素材编号区分。
3. **核对数量区间与分步生成**：对照 `task-types.md`「素材输入建议」（主体图 1–8 个、主体音视频 1–5 个效果较好；超过 5 主体优先用单视图或拆分为多张独立视图）。超出推荐区间时，先把人物分组生成合成参考图，再用分组图生成最终视频。
4. **精简提示词**：避免把冗长剧本当提示词，减少模型理解混乱。

## 画面出现未要求的字幕 / Logo / 水印

- **未要求字幕**：保留“保持无字幕”；仅当用户要求画面完全无文字时才扩大为“画面不出现任何文字”，避免误删招牌、信件或商品包装字。参考素材里非必要的文字先用工具擦除再输入；业务允许时优先横屏生成（横屏出字幕概率明显低于竖屏）。
- **未要求 Logo / 水印**：保留“不生成水印或Logo”。

## 风格漂移（动漫漂成写实）

现象：想要 2D/3D 动漫，但参考图偏写实且未强调风格，结果漂移成真人写实。
对策：明确写风格定义词（如“2D 日漫风格”“3D 国风漫画”），移除主文件默认的胶片实拍摄影机预设。需要更精准时，先把参考图转成目标风格再生视频。

## 晃动 / 颠簸不够（手持感压不出来）

现象：按常规写了 `handheld` 或“剧烈晃动”，但画面依然过于平稳。
根因：仅在开头总述写抽象形容词（“剧烈晃动”“原地震动”“机位与车刚性绑定”）物理引导力弱，进入动作序列后容易被模型忽略。
进阶排错对策：

1. **把摄影机晃动写进动作序列（各个节拍）里**：不要只在开头总述段交代手持晃动，必须在动作序列的每一拍（`先……随后……最后……` 或各时间戳段）中同步写明 `handheld` 镜头的晃动状态，并绑定具体物理触发事件（如“随着人物每一步沉重迈步与狂风冲击，整个画框大幅度上下颠簸起伏、左右剧烈晃动偏移”“每一次车轮压过坑洼、碾过石块，整个画面猛地一顿、狠狠弹起再砸下”）。
2. **明确幅度、频率与残影**：在动作节拍中写明“大幅、高频地上下颠跳并左右猛甩，伴随明显运动模糊与抖动残影”，或“主体在剧烈晃动颠簸的画框中数次轻微偏离中心又被拉回”。
3. **更换带动态模糊的参考图**：静态清晰的参考图会抑制晃动，换一张本身带动态模糊的构图参考图，模型更敢给晃动幅度。
4. **撞击音效**：仅在用户明确要求撞击音时于对应节拍加 `<底盘哐当撞击声>`；未要求时仍遵守主文件默认声音规则。

## 常规提示词写法问题核对表

当出现以下现象时，直接对照主文件 `../SKILL.md` 对应条款修正提示词，不在正文中堆叠否定词串：

| 现象 | 根因 | 排错修正方式（详见 `SKILL.md`） |
|---|---|---|
| **镜中镜 / 后视镜反射构图崩坏** | 模型难以解析“画面里再嵌一层反射画面” | 见「画内可见性与动作因果」：征得用户同意后，改写为等价实拍机位（如“机位正对司机的正面特写”），去掉“镜面/反射/倒影”字眼。注意：普通透过玻璃拍摄不属于镜面反射，无需替换 |
| **方向指错（看向“左边/侧上方”乱看）** | 相对方位缺少坐标基准 | 见「画内可见性与动作因果」：优先写明确目标对象，无目标时改用“画面右上方”“画框左下角”等绝对画面坐标 |
| **固定机位却自己推近 / 景别漂移** | 构图对应时刻不清，或写了与人物走动冲突的恒定条件 | 见「单镜头时序与运镜」：有构图参考时明确素材对应时刻并写清固定机位；无构图参考且需恒定时正面写“镜头与主体距离、景别和画面大小全程恒定”；若镜头本就要移动或人物走向镜头，删去冲突的恒定条件 |
| **表演过火（五官乱动、重复做同一动作）** | 跳过概括直接堆叠多个五官细节，或把持续状态写成再次执行 | 见「表演细节与克制程度」：每拍精简为 1–2 个低幅可观察细节（保留必要操作与因果步骤），持续状态改用“始终保持”“继续” |

## 特效效果不符合预期

现象：纯文字描述复杂特效（如“数字 2999 倒计时出场”）出现无序跳变。
对策：改用参考视频定义特效——把目标特效视频作为输入，如`{{Mixed 1}}：数字 2999 的出场特效参考`。

## 声音与发音问题

- **视频结尾有突兀咔哒声 / 截断杂音**（常见于含旁白片段）：重新生成，或在剪映中对片尾音轨做音量包络线淡出（音频 → 音量包络线 → 在临近结尾处打关键点并将末尾拉至 0）。
- **中文多音字 / 生僻字发音不准**：先保留台词原文并补充读音说明。仍需尝试同音字替换时，明确向用户展示原文与供发音使用的同音字（如“螭龙山”→“吃龙山”），经用户确认后仅用于语音发音修复；画面字幕与正式台词文本仍保留原字。
- **音色参考偏差**：在素材绑定处补充细致的音色特征词（如`{{Mixed 1}}：角色甲音色参考，低厚温润、带细碎颗粒感的中年男声`），并让台词语气与参考音频风格一致。

## Seedance 2.5 专项能力排错

- **编辑 / 延长被误判成参考生成（画幅或内容重绘）**：按 `task-types.md`「一、先分有锁定还是无锁定」核对参数（`ratio=adaptive`，编辑须 `duration=-1`）与触发词；确认待处理视频直接写了“编辑 `{{Mixed N}}`”或“向后延长 `{{Mixed N}}`”，未误写成“参考 `{{Mixed N}}`”。
- **首尾帧生成时尾帧被拉伸变形**：输出宽高比严格对齐首帧；检查首尾帧图片画幅是否一致，并优先使用 `content.role=first_frame/last_frame` 参数方式（`ratio=adaptive`）。
- **延长视频衔接处画面跳变 / 回退**：在剪映等工具中逐帧检查接缝（排查起点：前一段末尾删减约 6 帧，后一段开头删减约 1 帧，视实际动作接缝微调，不机械裁掉关键动作）。若仍有跳变，连续长镜头优先重做延长衔接，或改用 `task-types.md` 的「视频无缝转场」补全过渡；仅在用户允许分切时才在切镜处拼接。
- **延长后画质劣化 / 音量落差**：按 `task-types.md`「四、延长视频」确认输入与输出均采用 **mov** 格式，优先用 Seedance 2.5 原生生成的视频做延长，减少反复续写叠加次数；两段音量或画面接缝明显时可用「视频无缝转场」过渡。
- **时间戳段落切得太碎或漏演剧情**：按主文件「单镜头时序与运镜」「约束与输出」复核每段动作量与秒数是否匹配，优先在既定总时长内重分配节拍；若用户指定的总时长确实容纳不下必要动作，先说明冲突并给出时长或精简方案，获用户同意后再改。
- **白模渲染四肢僵化 / 辅助线泄露**：按 `task-types.md`「白模参考 / 渲染」检查——粗粒度白模避免未补全动作序列的四肢/翅膀，细粒度白模输入前去除轨迹线、坐标网格与相机线框；提示词补“最终只呈现写实人物与场景，去除辅助网格与轨迹线”。
- **多宫格分镜生成静止 / 顺序错乱**：按 `task-types.md`「多宫格分镜 / 故事板」控制在 15 格以内，避免过度锐化或写满文字的杂乱分镜图，并在正文中补齐动作与运镜过程；需要紧密对齐各幅画面时建议改用「关键帧参考」。
