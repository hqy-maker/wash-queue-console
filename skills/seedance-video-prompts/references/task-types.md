# 任务类型与句式（Seedance 2.5）

先判断任务类型，再选对应句式。本文维护 2.5 任务参数与素材输入建议；文中提示词示例统一采用默认 `{{Mixed N}}`，实际编号按上传顺序填写；方舟 API/控制台交付按主文件整体转换；用户偏好、节拍选择、声音和输出规则统一见 `../SKILL.md`。

## 一、先分「有锁定」还是「无锁定」

- **有锁定**：素材会严格成为输出视频**时间轴上的一段**，是模型输出去适配传入的素材，因此会锁定输出视频的宽高比（有时还有时长）。→ 编辑 / 首尾帧 / 延长。
- **无锁定**：仅对素材做**语义上的参考**，用户可以自行指定输出视频的宽高/时长属性。→ 参考类任务 / 多宫格分镜 / 关键帧。

### 有锁定：编辑 / 首尾帧 / 延长

编辑/首尾帧/延长会根据输入素材**自动锁定部分生成参数，不支持用户自定义**：

| 任务类型 | 任务定义 | 锁定说明 | 触发条件 |
|---|---|---|---|
| **视频编辑** | 对原视频的画面或音频做编辑（替换视频主体、视频中对象增删改、局部画面重绘/修复等） | ・锁定**宽高比**，严格对齐待编辑视频；`ratio` 必须 `adaptive`<br>・锁定**时长**，基本对齐待编辑视频；`duration` 必须 `-1`<br>・建议 `output_format` 用 **mov** | 1. `content.role` 设为 `reference_image` / `reference_video` / `reference_audio`<br>2. 提示词含触发关键词之一：**编辑**、**增加/加上**、**删除/去掉**、**修改/替换/改成** |
| **首帧 / 首尾帧** | 输入 1 张图作首帧，或 2 张图分别作首帧和尾帧 | ・锁定**宽高比**，严格对齐首帧图；`ratio` 必须 `adaptive`<br>・**时长支持自定义** | `content.role` 设为 `first_frame` / `last_frame` |
| **视频延长** | 对原视频向前/向后延长 | ・锁定**宽高比**，严格对齐待延长视频；`ratio` 必须 `adaptive`<br>・**时长支持自定义**<br>・建议 `output_format` 用 **mov** | 1. `content.role` 设为 `reference_image` / `reference_video` / `reference_audio`<br>2. 提示词含触发关键词之一：**向前/向后延长**、**延续**、**续写** |

补充细节：

- 存在多个输入视频时，由模型根据提示词意图判定"待编辑/待延长的是哪一个"，所以提示词里要用实际素材编号明确指名，并绑定待处理视频的用途。
- 受模型输入帧处理机制影响，编辑任务输出时长可能与输入有轻微差异（**最大约 0.3 秒**），只是部分过渡帧被压缩，内容基本对齐、保持完整。**如果编辑输入的是 Seedance 2.5 自己生成的视频，输出时长不会有差距。**
- 首尾帧画幅不一致时**尾帧会被拉伸**，因此建议输入画幅一致的首帧和尾帧。
- 也可以不用 `first_frame/last_frame` 参数，而把图设为 `reference_image`、在 prompt 里写"{{Mixed 1}} 为首帧""{{Mixed 3}} 为首帧，{{Mixed 5}} 为尾帧"。这种方式**不锁定宽高比**，效果与首尾帧参考图相近但不完全匹配。**优先用参数方式。**

触发关键词示例：`{{Mixed 1}} 中加一些小动物`；`把 {{Mixed 1}} 的人物修改为 {{Mixed 2}}`；`删掉 {{Mixed 1}} 的背景音乐`；`向后延长 {{Mixed 1}}，{{Mixed 2}} 的角色从天而降…`；`向前延长 {{Mixed 1}} 5秒，{{Mixed 2}} 中的女人入画…`。

### 无锁定：参考任务 / 多宫格分镜 / 关键帧

参考类任务对输出视频的宽高比和时长**没有来自输入素材的锁定**。其中**多宫格分镜 / 故事板**主要提供大致的剧情参考（生成画面不会严格对齐分镜细节），**关键帧参考**则相对严格地对齐各张输入图；具体策略与写法见下文对应小节。

## 二、多模态参考（R2V）

从素材中提取部分元素，生成全新视频。基础写作结构与文生视频要素见 `techniques.md` §1。2.5 支持的参考维度：

| 参考类型 | 说明 | 细化能力 |
|---|---|---|
| **主体参考** | 参考人/物/场景/虚拟角色等主体的外观 ID / 声音 | 主体图参考；主体音视频参考；主体图＋主体音色音频参考 |
| **运动参考** | 参考图/视频的运动/动态信息 | 动作/表情/运镜/创意/特效等运动参考；运动＋主体参考 |
| **白模参考 / 渲染** | 输入粗粒度或细粒度白模视频，参考其动态信息进行渲染 | 白模＋主体参考；白模＋主体＋场景参考 |
| **风格参考** | 参考图/视频的风格 | 风格图/视频参考；风格＋主体参考 |
| **音频参考** | 参考音频的音乐/台词/音色等声音信息 | 音频（音乐/旋律/台词/音色）参考；音频＋主体参考 |
| **宫格分镜 / 故事板参考** | 参考分镜图的主体/构图/动作/剧情 | 多宫格分镜参考；分镜＋主体参考 |
| **关键帧参考** | 输入单/多个图作为关键帧生成视频 | 关键帧分镜参考生视频；首帧/首尾帧参考生视频 |

推荐句式（实际多素材组合按上传顺序绑定）：

- 图片参考：`{{Mixed 1}}：角色甲形象参考。生成……`
- 视频参考：`{{Mixed 1}}：仅参考运镜。生成……`
- 音频参考：`{{Mixed 1}}：角色甲音色参考。生成……`

### 白模参考 / 渲染

**粗粒度白模**（预演用）：

- 支持输入含**运动、运镜、动线和光照**等动态/时序信息的白模视频；还支持叠加输入**主体、场景和道具**等参考图控制渲染效果。
- 当前版本对**简单建模**的参考效果较好，建议仅用**简单几何体**拼接表示人物/物体/动物。
- 白模视频主体建议**仅保留躯体**，避免包含“四肢/翅膀”等涉及精细运动的元素；如已包含，需补全其动作序列，以防渲染结果出现四肢僵化。

**细粒度白模**（重渲染用）：

- 服务于建模完整、重点解决重渲染的场景，给"白模上色"获得更丰富的渲染效果。
- 尽量提供完整且清晰的细粒度白模视频，**不含“轨迹线”“坐标线”“相机 cone”等干扰信息**，否则容易泄露到生成后的视频中。

写法要点：

- 文本中写明希望参考白模视频中的**什么元素**。白模中没有光影变化、只希望参考运镜和运动 →「参考 {{Mixed 1}} 的运镜、动作…」；白模有光影变化且需要参考 →「参考 {{Mixed 1}} 的光影变化和…」。
- 叠加了参考图时，写明**参考图和白模的对应关系**。示例：「{{Mixed 1}} 为白模视频；{{Mixed 2}} 中的男人对应红色模型，{{Mixed 3}} 中的少女对应绿色模型」。
- 输入白模视频后，仍需补齐目标成片中素材没有表达或用户要求改变的内容，并与所选参考维度相容；已绑定的完整动作不逐帧复述。没有形象参考时，按主文件用少量稳定特征定义主体。

### 多宫格分镜 / 故事板

- **减少超多分镜输入**：数量建议见本文「素材输入建议」；单次输入过多容易静止或顺序错乱，确保分镜准确、合理。
- **避免脏/锐化的分镜图**：不推荐过度锐化、杂乱的 AI 直出分镜图；不推荐在分镜图上写过多文字。
- **prompt 避免前后矛盾**：注意避免 prompt 前后矛盾或运镜、运动设计不合理。
- **宫格图并不会严格对齐分镜内容**，视频会有一定自主性发挥；如需更紧密地对齐各幅画面，推荐改用**关键帧参考**。
- **火柴人/线稿分镜使用（推荐）**：用相对简约的线稿分镜图，并通过 prompt 做指令控制，三步走：
  - step1：写明参考素材的指代关系
  - step2：写整体故事梗概
  - step3：按照分镜完整描述情节内容，至少补齐分镜图中没有的信息（动作、运镜、风格等），节拍格式遵循主文件，不因使用分镜图自动改用时间戳
- **概念分镜使用**：如果分镜是概念分镜或关键帧设计，可以直接简写 prompt。示例：「{{Mixed 1}}：概念分镜参考。按照 {{Mixed 1}} 分镜图的顺序，构建一个完整的故事剧情，运镜合理连贯」。

### 关键帧参考

视频需要比多宫格更紧密地对齐各张图时使用；不把语义关键帧参考等同于参数锁定的首尾帧。将分镜作为独立素材按顺序传入，提示词第一句同时说明素材范围和用途，如“以 {{Mixed 1}} 至 {{Mixed 3}} 的顺序作为关键帧”；随后补齐其他素材映射。

句式：`以 {{Mixed 1}} 至 {{Mixed 3}} 的顺序作为关键帧，接一句话概述，再写动作和时序。` 示例见 `examples.md` 的「多宫格分镜与关键帧参考」。

## 三、编辑视频（含参考图组合编辑）

在原视频基础上局部或全局修改，未提及的部分保持不变。2.5 分三种：

1. **视频指令编辑**：通过文本对视频画面进行增删改编辑，**支持输入时间戳指定编辑生效时段**。
   - 增加：增加主体/服饰/运镜/特效…
   - 修改：修改主体/主体局部/风格/背景/颜色/材质/运镜/机位…
   - 删除：删除主体/字幕/水印…
2. **视频参考图编辑（组合任务）**：参考某个图片/素材，编辑另一个视频素材，同样支持时间戳指定生效时段。
3. **视频音频编辑**：对视频声音进行增删改——增加/修改/删除人声、音乐、音效。

写法要点（官方"编辑类"规则）：

- **关键**：对待编辑/延长的视频直接写“编辑 {{Mixed 1}}”或“把 {{Mixed 1}} 中的……修改/替换为……”；不要对目标视频写“参考 {{Mixed 1}}”，以免被误判为参考生成。组合任务中先指明待编辑视频，再对辅助素材写“参考”或直接指代。
- 明确需要修改的**范围和内容**，用户明确指定或同意后可配合时间戳进行部分编辑，尽可能说明修改内容**从 A→B 的过程**。
- 示例 1（台词/口音编辑）：「仅编辑 {{Mixed 1}} 中男人的台词，修改为{你不要过来啊}，口音调整为东北口音，其余保持不变」
- 示例 2（局部时段编辑）：「把 {{Mixed 1}} 中 4–6 秒男人喝咖啡的动作改变为拖地，其余内容不要变化」
- 示例 3（参考图组合编辑）：「编辑 {{Mixed 1}}，把 {{Mixed 1}} 中右侧的亚洲女生修改为 {{Mixed 2}} 中的黑人女生，其余保持不变」
- 示例 4（音频翻译编辑）：「将 {{Mixed 1}} 中的人声台词翻译成中文，保持无字幕，口型做出对应的精准改变，其余均保持不变」

## 四、延长视频

时间维度上延续原视频，要求音视频风格、主体与叙事一致。适用：续写剧情、延展动作、补全片段。

推荐句式：`向前/向后延长 {{Mixed 1}}，新增片段为N秒，从原视频……直接继续……`

注意事项：

- 模型自动截取衔接部分进行合成，输入视频原有片段不会重复生成。
- 为获得最佳的声画衔接效果，**输入视频、输出视频均采用 mov 格式**。
- 延长任务生成视频的**音量较输入视频可能发生轻微变化**；输入 Seedance 2.5 自己生成的视频做延长，音量变化相对较小、无缝衔接效果更好。
- 默认从原片衔接处的既成构图、姿态和动作继续。新增片段时长可指定或推荐，并与原片总时长区分。只有用户明确要分段或场景切换时，才考虑在切镜处衔接。

## 五、一键成片与视频无缝转场（2.5 新增）

- **一键成片**：输入多个图/视频生成短片，可添加文字/贴纸/转场等。支持"素材一键成片"与"素材＋参考视频一键成片"。句式：先写“将本次上传的全部图片一键成片”，再说明顺序、风格/题材、音频要求及是否允许改动原图。
- **视频无缝转场 / 多段轨道补全**：输入两段或多段视频，模型生成过渡画面补全间隙，实现无缝衔接。
  - 两段衔接句式：`{{Mixed 1}}：前段视频。{{Mixed 2}}：后段视频。将 {{Mixed 1}} 和 {{Mixed 2}} 衔接起来，描述前段片尾运动、过渡过程与后段起幅，保持上传的两个视频原片段不变。`
  - 多段轨道补全句式：`衔接 {{Mixed 1}}、{{Mixed 2}} 和 {{Mixed 3}}，依次描述各段之间的过渡画面，保持上传的原视频片段不变。`
- **自由组合能力**：上述参考、编辑、延长与转场能力可按实际需求组合应用。适配示例见 `examples.md`。

## 六、连续长镜头 vs 分段拼接

- **连续长镜头（直出或视频延长）**：适用单一场景的"文戏"——长对话、情绪递进、单一路径移动，实现沉浸式一镜到底。2.5 单段可直出 30 秒，很多原来需要拼接的段落现在一条就够。
- **场景/动作转折（分段拼接）**：适用剧情转折或复杂快速的"武戏"——追逐、打斗、蒙太奇，独立生成片段再剪辑组合，保证节奏与冲击力。
- 实际制作常结合两者：先用延长生成连贯对话，再拼接空镜或转场片段；两段之间衔接不顺时可用"视频无缝转场"补间隙。

## 七、素材输入建议（2.5 官方推荐值）

单次可输入图像/音频/视频**最多 50 个参考素材**，这些素材可能指向同一个或不同的主体（人物、动物、道具、场所等）。为了充分激发模型能力：

| 场景 | 输入建议 |
|---|---|
| 输入素材总上限 | 图片：最多 **30 张** 4K 分辨率以内的图片；视频：最多 **10 段**，总时长不超过 **30s**；音频：最多 **10 段**，总时长不超过 **30s** |
| 主体音视频，输入多少个主体 | **1–5 个**效果较好；6–10 可尝试，但稳定性下降、可能需要抽卡 |
| 主体音视频，输入多长时间 | **5–10s** 效果较好；更长时长稳定性下降、可能需要抽卡 |
| 主体图，输入多少个主体 | **1–8 个**效果较好；9–12 可尝试，但稳定性下降、可能需要抽卡 |
| 不同视角主体图的输入效果差异 | 1–5 主体，「单视图」「多视图」均可；**超过 5 主体，「单视图」效果较稳定**；如需输入多视角，建议**拆分为多张不同视图输入**，而非输入一张包含多视角的图 |
| 宫格图参考，输入多少个分镜 | 多宫格目前更适用于 **15 个以下**分镜；素材处理见本文「多宫格分镜 / 故事板」 |
| 视频编辑，输入多长的视频 | **20s 以内**效果较好；更长时长稳定性下降、可能需要抽卡 |
| 视频参考图编辑，输入多少张图 | **1–5 张**效果较好；6–8 张可尝试，但稳定性下降、可能需要抽卡 |
